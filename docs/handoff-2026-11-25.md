## 3. 매니저 허브에 가져올 요소
**바로 가져오기 좋은 것**
1. 팁 카드 형식("문제 → 해결 → 사용법 단계 → 바로가기")을 자료와 Q&A에 적용.
2. 상황별 체크리스트 (예: 신상품 출시 주간, 개정 반영 주간).
3. 기준일과 "참고용" 표시를 더 눈에 띄게 (FAQ 근거·기준일, 재검토 배지).
4. 홈 상단 도구 바로가기 줄 (최신 1매형, 약관 찾기, 질문하기, 긴급공지).
5. 홈 카드에 업데이트 날짜 표시.

**검토할 것 (정책 결정 필요)**
6. 카톡 공유용 이미지 버전 — 반드시 `audience` 정책(internal/planner/customer)과 연결.
7. 상품별 "설계사용 안내 링크" 한 장 (보험인ID 방식, 카톡방 공지용).
8. 리플렛 썸네일 그리드 — 회원 업로드는 승인 절차와 충돌하므로 제외.
9. 앱 설치 / iPhone 홈 화면 추가 안내 페이지 (PWA).

**가져오지 않는 게 좋은 것**
- 익명 블라인드 후기, 채용공고, 유료 전자책, 광고 배너 (사내 상품지원 허브 목적과 맞지 않음).
- 단체문자·주소록 같은 연락처 처리 도구 (개인정보. 들인다면 별도 보안 검토 먼저).
